## Sobre o projeto

Analise estatistica dos planos pre-pagos Surf e Ultimate da operadora ficticia Megaline, com o objetivo de identificar qual plano gera mais receita e orientar decisoes de investimento em campanhas publicitarias. Projeto desenvolvido no Bootcamp de Analise de Dados da TripleTen Brasil.

## Pergunta de negocio

Qual plano pre-pago - Surf ou Ultimate - deve receber maior investimento em publicidade?

## Principais insights

- O plano Ultimate e menos contratado, mas gera maior receita por usuario
- - O consumo medio de dados e chamadas e semelhante entre os dois planos
  - - Recomendacao: direcionar marketing ao plano Ultimate para maximizar ROI
